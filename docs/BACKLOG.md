# Backlog

Не сделано в Ф5 (2026-11-11, решение пользователя: Ф5 закрыта на моделях).

- **Форматирование дискет из Мака** (Finder Erase Disk / Initialize): на плате «Initialization failed!». У NanoMac его нет. MiSTer (b340c9f, «Erase Disk»): ROM требует, чтобы после записи дорожки первым увиденным полем адреса был сектор 0, а сторона чтения кодека шла сама по себе — кодер переносит позицию чтения туда, где формат положил сектор 0 (по адресной метке от декодера). Плюс сторонность носителя: One-Sided на образе 819200 байт — диск 400 КБ (MiSTer смотрит заголовок тома). У нас другой кодек (`floppy_track_codec` + `floppy_track_buffer`): логику повторять там, с iverilog-тестом записи дорожки форматом. Пока: пустые образы — готовым файлом (например, копия чистой дискеты 800 КБ).
- **Дисковод 400 КБ у 128K / 512K**: скорость шпинделя задаётся программно — ШИМ из младших 6 бит слов звукового буфера (MiSTer `rtl/disk_pwm_duty.v`: таблица 64 значения, сумма за 100 отсчётов); без неё цикл скорости ROM 64K не сходится, дискету модели, скорее всего, не прочтут (на плате проверен только «?» без диска). 512K читает сторону 0 образа 800 КБ.
- **HD20** (MiSTer `dcd_link.v`, `dcd.v`, `dcd_disk.v`, daisy chain в `iwm.v`).
- **Модем** через ESP (SCC → UART), **MIDI** (SCC → прошивка / SAM2695).
- **Клавиатура и мышь SE (ADB)** на плате не проверялись (SE дошёл до «Welcome to Macintosh» сам).
- `mac_clock` ~800 LUT: общий сумматор / вычитатель с выбором константы вместо отдельного на 86400 / 3600 / 60.
- Go и Mini на платах не запускались.

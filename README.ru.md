# Ядро Apple Macintosh Plus для Karabas Go / Mini / Mini G

[English version](README.md)

Apple Macintosh Plus для плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25). Это порт [NanoMac](https://github.com/MiSTle-Dev/NanoMac) Тилля Харбаума, который основан на портах [MiSTer](https://github.com/MiSTer-devel/MacPlus_MiSTer) и [MiST](https://github.com/mist-devel/plus_too) проекта [Plus Too](https://www.bigmessowires.com/plus-too/) Стива Чемберлина.

| Плата | Файл ядра | Видео | Звук |
|---|---|---|---|
| Karabas Go | `macplus.kg` | VGA | I2S ЦАП (PCM5102) |
| Karabas Mini | `macplus.kg` | HDMI | HDMI, аналоговый выход (сигма-дельта) |
| Karabas Mini G | `macplus.kg` | HDMI | HDMI, I2S ЦАП |

Файл ядра лежит в `src/`. ПЗУ Макинтоша и системное ПО принадлежат Apple: их нет ни в репозитории, ни в файле ядра. Свой файл ПЗУ положите на SD-карту.

Состояние: проверено на Mini G. Сборки для Go и Mini на платах ещё не запускались.

## Что умеет

- **Процессор:** 68000 на 7,7 МГц (fx68k; у Mac Plus 7,83 МГц).
- **Память:** 1 или 4 МБ ОЗУ (пункт OSD Memory), ПЗУ Plus 128 КБ с SD-карты.
- **Видео:** 512 × 342, монохром, на выходе 1024 × 768 60 Гц, каждая точка 2 × 2.
- **Дискеты:** два дисковода 800 КБ (внутренний и внешний), образы `.dsk`, чтение и запись.
- **Жёсткие диски:** два диска SCSI (ID 6 и ID 5), образы `.vhd` / `.img` / `.hda`, чтение и запись.
- **Часы и PRAM:** при старте часы Мака берут время у часов платы, а время, выставленное на Маке (Control Panel), уходит обратно в них. PRAM (настройки Control Panel) хранится в `/config/macplus.eep` на SD-карте.
- **Ввод:** USB-клавиатура и мышь.
- **Звук:** 8-битный звук Мака.

Образ, подключённый «только для чтения» (в файловом браузере OSD), — диск с защитой от записи.

Не поддерживаются: последовательные порты (модем, принтер), физический дисковод Go, модели SE / 512Ke / 128K.

## Как начать

1. Скопируйте `macplus.kg` (один файл для Go, Mini и Mini G) в корень SD-карты.
2. Положите ПЗУ Mac Plus как `/macplus/plus.rom` (128 КБ; работает ПЗУ Plus v3, контрольная сумма 4D1F8172), а образы дисков — в `/macplus`.
3. Выберите Mac Plus в меню ядер. Без диска Мак показывает дискету со знаком вопроса. Откройте OSD (**Menu+Esc**) и вставьте системную дискету в Floppy 1 (System 6.0.x на дискете 800 КБ работает).

«Menu» — клавиша Windows на клавиатуре.

## Меню OSD

| Пункт | Значения | Горячая клавиша |
|---|---|---|
| Floppy 1, Floppy 2 | образ `.dsk` / `.img` (800 КБ) | Menu+F1, Menu+F2 |
| SCSI 6, SCSI 5 | образ `.vhd` / `.img` / `.hda` | Menu+F3, Menu+F4 |
| ROM | файл `.rom` / `.bin` (загружается сам из `/macplus/plus.rom`) | Menu+R |
| Memory | 1 MB / 4 MB | Menu+M |
| Fastboot | Off / On: без проверки памяти и контрольной суммы ПЗУ при старте | |
| Reset | сброс машины | F12 |

Настройки и выбранные образы запоминаются.

Перед сменой ядра или выключением платы выключите Мак (Special > Shut Down): записи на диск Мак держит в кэше в памяти, и образ без них может перестать загружаться.

## Клавиатура

| Мак | PC-клавиатура |
|---|---|
| Command (Apple) | Alt |
| Option | Ctrl |

## Образы жёстких дисков

Образу диска SCSI нужна карта разделов Apple с драйвером; диск с пустым разделом Мак предлагает инициализировать (и сам пишет том HFS). Подходят образы `empty_hdd` ядра Mac Plus для MiSTer.

## Сборка

Клонируйте с `--recursive` (подмодуль `modules`). ISE 14.7: `cd src && make` для всех плат или `make minig` для одной. Верхи Mini и Go делает из верха Mini G `src/tools/mktops.py`. Проверки (Verilator, iverilog): `src/sim/run_checks.sh`. План и заметки о решениях — в [docs/PLAN.md](docs/PLAN.md).
